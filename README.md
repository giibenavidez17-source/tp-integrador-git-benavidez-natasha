# Lali Espósito - Sitio Fan

## Descripción

Este proyecto es un sitio web sencillo dedicado a Lali Espósito, cantante, actriz y compositora argentina. La página presenta información general sobre su trayectoria y su música.

## Objetivo

El objetivo del proyecto es aplicar los conocimientos aprendidos sobre Git y GitHub mediante la creación, versionado y publicación de un proyecto web sencillo.
